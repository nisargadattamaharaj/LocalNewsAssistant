### 5.1. Детали технической проверки тестов SUMMARY
- **H/L:** исключения builder / postprocessor обрабатываются корректно.
- **C/I:** освобождение координатора после ошибок (`IOException`, `IllegalStateException`) и успешный следующий `SUMMARY`.
- **N:** управляемый cleanup fake-сервиса, удержание `busy = true` во время финализации, отклонение конкурирующего запроса, последующий успешный запуск.
- **Подготовка (File check / Asset loader):** реальные `Job.cancel` во время ожидания финализации проверяют состояние `Idle`, завершение Job и освобождение координатора.
- **Синхронный возврат / отмена:** самоотменяющийся сервис корректно возвращает нормальный результат без `Success` и без вызова постпроцессора (`postProcessorCallCount == 0`). Отмена checker до возврата `Invalid` не вызывает ложный `onModelCorrupted`, переводя состояние в `Idle`.
- **Исключения отмены:** проверка прямого проброса `CancellationException` через `assertSame`.
- **Пустые / пробельные ответы:** отклоняются до постпроцессора (`postProcessorCallCount == 0`) с переводом в `Error`.
- **Сохранение черновиков:** неструктурированный ответ и неизвестный ID сохраняются как черновик с предупреждениями и корректными флагами.
